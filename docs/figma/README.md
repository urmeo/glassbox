# Pipeline sources

[Edit the GlassBox pipeline in Figma](https://www.figma.com/board/0Hzi29Tu1WkqLkY0tkT6nQ/GlassBox-pipeline?node-id=4-65).
The board contains editable text, grouped stages, and connected arrows.

The README uses [pipeline.svg](../img/pipeline.svg). Rebuild it from the repository root
with `python3 docs/make_pipeline.py`; no browser or extra package is required.

[pipeline.mmd](pipeline.mmd) records the connections in Mermaid. It does not preserve
the board layout. Figma and the SVG source are edited separately; keep their labels
and connections consistent when the project changes.
